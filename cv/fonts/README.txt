IBM Plex Sans — static TrueType instances (400, 500, 600, 700).
Source: https://github.com/google/fonts/tree/main/ofl/ibmplexsans
Input: IBMPlexSans[wdth,wght].ttf; wdth=100, wght=400/500/600/700.
Instances generated with fonttools 4.68.0, instantiateVariableFont(...,
    inplace=False, updateFontNames=True).
The four committed instances are the only fonts needed for HTML/PDF export.
No runtime fonttools dependency or system font installation is required.
